# Codex reporting requirements

This is a standing requirement for WallSprint Codex tasks.

Every Codex completion report must include a concise test/validation section. At minimum report:

- the test or verification procedure performed;
- the exact command(s) executed;
- the expected result;
- the actual result;
- any test that was not performed and the exact reason it was not performed.

Do not report an unexecuted test as PASS. Distinguish owned fixture/static validation from actual game/runtime validation.

When `docs/CODEX_NEXT.md` defines stricter task-specific validation, follow both this standing rule and the task-specific requirements.

The report should also identify the branch and commit SHA containing the completed work and state whether owner-side action is required.
