## Raw ABI transparency

writer_entry_thunk.S independently uses the existing project's proven save/tail-jump scheme, extending it to all15 GPRs plus RFLAGS. It saves original x87/MXCSR/XMM state with aligned FXSAVE64 and all YMM0..15, supplies raw stack-frame/FXSAVE addresses to a noexcept read-only callback, restores every saved state and tail-jumps through the original trampoline. Entry RSP is the untouched return slot at Frame+128. Return address/stack arguments are not replaced. LastError is saved/restored by the callback. No typed writer prototype or post-return adapter is invented.

Callbacks perform bounded guarded reads, coherent identity checks and immutable record publication; allocation-free owned record arrays/no callback log or decoder/hash/no worker lock wait. Compiler/runtime TLS machinery follows the existing thread-local project pattern. At most8 eligible entries/session and8 windows/process (64 immutable records),64 stack bytes at entry RSP+0x28,16 XMM lanes groups,16 GPRs and three16-byte reads at argument RDX/R8/R9. Stack reads also require current TEB bounds; guard/noaccess/cross-region/overflow reads fail without changing protection. Snapshot values are true entry-before-body observations, with separate readability fields and raw bits; multiple guarded reads are not one atomic engine snapshot.

## Explicit invocation pairing

Every hooked entry invalidates recycled RSP tokens, including unrelated target/caller/cap-rejected calls. An eight-frame thread-local stack associates unique immutable record ID with original entry RSP. Nested calls retain outer tokens; concurrent threads cannot use each other's tokens. Overflow loses evidence rather than reusing an outer ID. No generic call is required to match.

Existing c11 hardware unwind records the actual first return slot. Only writer-body events on the same session/generation/TID/Transform/return and exact entry RSP receive the token, with fresh identity/current owned-code proof again. POSITION_WRITE_EVENT carries invocation_id. Every eligible event reaches the new worker aggregate before c11's unchanged4-print/identity cap; the raw256/window and all DR/snapshot/cleanup caps remain.

Worker fully decodes the saved original183 bytes and anchors the instruction ending at captured RIP. Only supported scalar MOV/MOVSS/VMOVSS stores with exact effective Hero+0x30/34/38/3c are accepted. Written bits come from the captured unchanged source GPR/XMM or immediate operand, not a target-memory reread that another CPU may already have overwritten. The observed target-after row is logged separately and remains non-atomic. Duplicate/unknown/partial events cannot produce a full invocation proof. Saved originals are used for c12 inspection only when the live complete writer matches our authenticated patch; foreign code cannot be substituted as original.

No return boundary is intercepted: four components mean four same-invocation store events, not whole-function return, downstream exclusivity or intended native motion. Worker drains incomplete records only after event queue/inflight handlers settle. Entry records/trampolines persist to process exit to prevent ABA/inflight reuse.
