## M6u / setter disassembly (owner camera_code.json from dump_camera_code.py; decoded in the cloud; bytes NOT committed)
VERIFIED-STATIC (exact EXE c9b912ef…38c9, setter 0x3350220-0x3350504):
- Inputs: rcx = mover, rdx = forward vec3, r8 = up vec3, r9d = flags (kept in ebp).
- The forward input is orthogonalized against up. The current view direction is rebuilt from the mover floats +0x2CC (yaw) and +0x2D0 (pitch) through a helper and the old reference matrix at mover+0x210.
- A new reference matrix is built from (up, forward) and stored at mover+0x210. The view direction is then expressed in the new frame.
