# M8 — WS jump / charge jump (stage 3) plan, 2026-11-06

## Owner direction
- WS jump should look like the ground sprint jump. Owner proposed replacing the WS jump clip with the ground sprint
  jump clip, then moving on to the gravity-keeping jump.
- Charge jump is wanted too. For now, only the variants that come from a ground sprint are needed (sprint jump,
  sprint charge jump).
- Design choice to keep open: keep vanilla's vertical-WR web-climb jump (sling up); WS jump only on charge jump, or
  replace it. Decide after M8a.

## M8a (this build) — one change
`ws_assets.CLIP_SWAPS` places the ground sprint jump clip at the 3 Peter / 4 Miles sideways WR jump clip paths above.
Toswing, sling_up, vault, dodge and overhang jumps are unchanged.

| Result in game (jump from WS, sideways) | Decision |
|---|---|
| Pose is the ground sprint jump, no crash | Swap accepted; later narrow to the clip actually used if needed. Next: orientation return / gravity-keeping jump |
| Pose unchanged | The used clip is another path -> ask for a search on `jump` excluding the above |
| Pose changes but breaks (stuck in jump, wrong state, T-pose) | Clip events/length incompatible -> revert and look at the clip event table |
