## Independent bounded address model

The legacy State/Slice, straight-line writer, c16 classifier and caller/producer APIs remain unchanged. New alias analysis receives the exact writer pre-call abstract GPR/vector/stack state on every relevant c15 writer path. Entry-writer RDX is distinct from call-time RDX; RCX/RDX/R8/R9 origins/offsets and source/Transform candidate masks print in MOVEMENT_WRITER_CALL_ARGUMENT_CONTRACT. Unknown arguments remain labeled unknown; they never become distinct safe objects merely because their symbolic roots differ. Unknown unused arguments need not prevent a stack-only effect proof; write-dependent unknowns refuse. Conflicting pre-call argument origins refuse.

Exact address roots: entry-writer RCX/Transform, entry-writer RDX/source, writer-entry RSP and exact in-image RIP-relative address. Simple MOV/LEA/add/sub chains retain exact roots/offsets. Source root is normalized to writer-entry RSP+0x28 **conditionally on existing invocation storage admission**, never from equal bytes alone. Pointer values loaded from memory, unsupported indexed/segmented/32-bit addresses and unmodeled effects remain unknown. A RIP-relative LEA can supply a global pointer, but no global pointer slot is dereferenced/chased.

Callee branch targets must be forward, local and instruction-aligned. Both flag-Jcc successors are enumerated without solving flags; direct forward JMP stays local. No recursion, nested-call expansion, indirect transfer, backedge/fixpoint or producer traversal. Hard caps:137bytes,4 branches,16 pending paths/31 scheduled states per call,16 writer call states,64 total return paths,4096 total callee instruction visits and24 unique memory-write sites. Complete decode is mandatory; missing/unbalanced return or cap overflow refuses exactly.

Each reachable write records site/width/root/offset/class. Counts are unique analyzed instruction sites, not dynamic execution counts; a failure covers only the explored prefix. Reaching states must agree on the exact write origin: even two different safe addresses at one site refuse as conflicting provenance. All visits check for overlap with writer's pre-call saved stack carriers. Decoded callee saves/restores establish nonvolatile preservation; volatile GPR/XMM0..5 are always invalidated. W remains independent.

## Write classes / conditional disjointness

- callee_private_stack: known current allocated frame below callee-entry RSP, within bounded stack offsets. PUSH/POP and supported scalar/vector saves/restores are modeled.
- caller_shadow_or_return_area: natural return slot refuses; only the exact32byte home region after that slot can be accepted, provided source, writer return and saved-carrier exclusions pass. Foreign/unallocated stack writes refuse.
- source_span_exact: any write overlapping source16bytes refuses; byte equality cannot excuse it.
- hero_transform_exact / hero_transform_possible_alias: protected Transform+[0,0x40) overlap or unproven object extent refuses.
- rip_relative_global: exact write wholly inside authenticated image; **conditional** on runtime stack/source and full protected Transform range being outside that image. Different pointer values alone do not establish disjointness.
- known_disjoint_object: only an exact bounded stack-derived range with protected-source exclusions; unsupported store semantics may still refuse. No arbitrary argument object is declared disjoint.
- source_span_possible_alias / unknown_pointer: unresolved address/provenance refuses. Labels describe proof knowledge, not a guess that a write actually occurred on the sampled CPU path.

The natural CALL return push, possible callee writes and home writes contribute min/max writer-entry stack offsets. Before per-invocation XYZ/W flags, the whole footprint must fit captured current-thread TEB bounds; source must equal entryRSP+0x28 with bounded equal guarded samples; Transform must be nonstack. For image-global writes, whole TEB stack and protected Transform range must exclude the image. This protects both source and destination without guessing alias freedom. Returned writer registers use conservative masks; caller saved-slot overlaps refuse rather than leaving stale cached values.

MOVEMENT_CALLEE_ALIAS_CONTRACT reports bounded counters, source/Transform no-write flags, all-resolved, caps and exact next callee barrier/mnemonic/effect/address root/offset/width.
