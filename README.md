# WallSprint

v0.1c22 / package0.1.40 adds bounded diagnostics for the pinned TEST at0x2B235BE after accepted c21 read0x2B23578 (Transform+0x10C -> EAX) and possible local control dependence. Read-only register TEST reports exact operand names/widths and separate selected/new/other field tags, flags and consuming local branches. Low-byte reads use conservative parent tags; unsupported partial writes/high-byte/16bit/memory/immediate forms still refuse. Actual c22 operands/next blocker await a new game log. No effect/XYZ/W/ownership certificate, Position/source-position/input/movement writes or producer traversal.

Use `MSM2-WS-v0.1c22.zip` and the included `Migrate-WS.cmd` outside Mods Library. The authoritative clone is `<game>/Mods Library/Mods-Developing/MSM2-WS/_source`; normal updates use `MSM2-WS/Update-WS.cmd`. Exactly one active versioned `.script` remains at workspace root. Overstrike also scans ZIP contents: the independent source clone excludes archives from its working tree using managed Git sparse checkout, and build-cache ZIPs are retained only as `.zip.disabled`. Code and release archive history/downloads remain in GitHub. Shared Overstrike is `<game>/Overstrike/Overstrike.exe` with game-root WorkingDirectory. SF/ordinary mods and the legacy environment are never cleaned or automatically removed.

See [README_TEST.md](README_TEST.md), [docs/LOCAL_WORKSPACE.md](docs/LOCAL_WORKSPACE.md) and [source/BUILD.md](source/BUILD.md) for Python/Git/WSL prerequisites, first migration command and real-PC acceptance checks. Runtime logs use `MSM2-WS/logs/MSM2-WS-v<version>-YYYYMMDD-HHMMSS.log` without fallback. Cloud fixture success is not a claim that the user's PC was migrated.
